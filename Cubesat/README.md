# CubeSat Flight Software

This folder contains subsystem and flight software developed by me for a 3U CubeSat mission.

## What this includes
- Sensor base code and calibration (environmental, optical, gas)
- GPS data acquisition and logging
- Communication experiments (LoRa / TX-RX)
- SD card logging
- Integrated multi-sensor flight builds

The code reflects a modular development process: individual subsystem validation followed by integrated flight software.
