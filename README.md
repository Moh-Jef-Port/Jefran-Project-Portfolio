# Engineering & Maker Portfolio – Mohamed Jefran

This repository contains selected programming and embedded systems projects submitted as part of my MIT Maker Portfolio.

## Key Projects

### 🛰 CubeSat Flight Software
The `Cubesat/` folder contains modular flight and subsystem code developed for a 3U CubeSat launched to the stratosphere.  
It includes sensor bring-up, data logging, communication, and integrated flight builds using Arduino and STM32 platforms.

### 🚗 Arduino & PID Control
The `Arduino/` and `PID/` folders include embedded control systems such as a Bluetooth-controlled vehicle and PID-based motor control experiments.

### 🧠 Computer Vision & AI
The `CV & AI/` folder contains experiments in Python related to computer vision and basic AI workflows.

### 📱 Swift / App Development
The `Swift/` folder contains iOS and Swift-based projects focused on application development and human–computer interaction.

### 🚀 Industry Research (Space Copy)
The `Space Copy/` folder contains non-sensitive, portfolio-safe code and materials related to my internship in aerospace and in-space manufacturing research.

Each folder contains source code written by me and organized for portfolio review.
